# CSC 20 - Matrix Calculator

A Java application demonstrating object-oriented programming
through numerical and string matrix operations.

## Features

### Numerical Matrix
- Matrix addition
- Matrix subtraction
- Element-wise multiplication
- Standard matrix multiplication

### String Matrix
- Combines corresponding elements of two string matrices
- Uses a word library to generate custom combinations

### Word Library
- Predefined word combinations
- Add custom combinations using the GUI
- Combination lookup using HashMap

## Technologies
- Java
- Java Swing
- Object-Oriented Programming

## How to Run

Requires Java JDK 17 or newer.

Compile:
javac -d out src/arrayops/*.java

Run:
java -cp out arrayops.MatrixGUI
